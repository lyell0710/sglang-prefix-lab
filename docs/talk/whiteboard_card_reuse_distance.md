# 白板推导卡 · LRU 重用距离模型


**推导目标**:预测前缀缓存何时命中、何时崩塌。
1. 定义重用距离 D:同一热前缀两次访问之间注入缓存池的 token 总量。
   轮转访问 H 个热前缀、每次总长 T、每热请求跟 c 条冷请求:
   D = H·T·(1+c)。
2. LRU 命中条件:池容量 P ≥ D(被复用前不被逐出)。
3. 预测阶跃而非衰减:P 略小于 D 时,每个热前缀恰好在重访前被逐出
   ——循环工作集是 LRU 最坏情形,命中率 1.0→~0(实测 std=0,EXP-P05《逐出压力》)。
4. **面试点**:容量规划按重用距离而非热集大小;cache-aware 路由的本质
   是改变每卡看到的 D(EXP-P06《路由 × 池容量》:亲和集中反而放大 D 导致崩)。
